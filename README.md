一款簡單易用的HEIC照片批次轉換工具，支援多執行緒加速處理，可將手機拍攝的HEIC格式照片快速轉換為JPG格式。

## ✨ 特色功能

- 🚀 **多執行緒處理** - 比傳統單執行緒快2-4倍
- 📁 **批次轉換** - 一次處理整個資料夾的所有HEIC檔案
- 📂 **靈活輸出** - 可選擇輸出到相同資料夾或子資料夾
- 🎨 **品質控制** - 自訂JPG壓縮品質(1-95)
- 🤖 **智慧模式** - 自動選擇最適合的轉換模式
- 🎛️ **多種模式** - 慢速(穩定)、快速(推薦)、智慧模式
